3. AUTHENTICATION PROVIDER & ENVIRONMENT CONFIGURATION
--------------------------------------------------------------------------------
• Provider Support:
  - Supabase Auth: When configured via client environment variables:
      VITE_SUPABASE_URL="https://<your-project>.supabase.co"
      VITE_SUPABASE_ANON_KEY="<your-anon-key>"
    The login page authenticates directly with `supabase.auth.signInWithPassword`.
  - Offline Counter Authentication:
    When environment variables are unconfigured or when offline, SLATE POS 
    automatically falls back to validating credentials against the registered 
    local staff roster. The login screen displays an informational notice 
    indicating that local offline authentication is active.
  - Security Notice:
    Supabase service-role keys are strictly server-side and never exposed in 
    client bundles.
